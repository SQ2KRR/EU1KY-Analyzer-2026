# EU1KY Analyzer 2026

Multilingual firmware and documentation for the EU1KY Antenna Analyzer based on STM32F746G-DISCO.

This project is based on the original EU1KY Antenna Analyzer firmware and later development by DH1AKF, KD8CEC and other contributors.

The work started with the addition of a Polish user interface. During testing, a number of smaller corrections and improvements were also introduced.

## Current release

**EU1KY-PL 2026 v2.01**

Ready-to-use firmware will be available in the **Releases** section.

## Languages

The firmware includes multiple interface languages.

Detailed information about the currently supported languages will be added here.

## Documentation

A complete Polish user manual is available for firmware version 2.0.

Version 2.01 contains only minor changes, therefore the v2.0 manual remains applicable.

Additional language versions of the documentation are planned.

## Hardware

The firmware is intended for the EU1KY Antenna Analyzer based on:

- STM32F746G-DISCO
- EU1KY RF front-end
- Si5351 frequency synthesizer

Optional extensions supported by this development include additional controls and diagnostic functions.

## Project origin

This is a continuation and modification of the work created by the EU1KY amateur radio community.

Original project and major contributors include:

- Yury Kuchura, EU1KY
